# Build a Premium Salon & Beauty Directory Website

I want you to **design and fully develop a modern, premium, visually stunning, responsive website** for a salon and beauty business directory in **Jaranwala and Faisalabad, Pakistan**.

The website should look like a **high-end professional salon/beauty platform**, not a basic business listing website. The design should feel luxurious, elegant, modern, smooth, and visually engaging.

The website must be **fully functional, responsive, fast, SEO-friendly, and production-ready**.

---

## 1. Website Purpose

Create a professional website that showcases a collection of the best salons, beauty parlours, hair salons, makeup studios, and spas in the Jaranwala/Faisalabad area.

The website should help visitors:

* Discover salons and beauty businesses
* View salon information
* See contact details
* View addresses
* See review counts
* Visit Instagram profiles
* Search for salons
* Filter businesses
* Explore salon details
* Contact salons easily
* Find salons based on categories and location

The website should have a **premium salon-inspired aesthetic** with beautiful typography, elegant animations, smooth transitions, interactive cards, and modern UI components.

Use a **luxury beauty and salon design system**.
